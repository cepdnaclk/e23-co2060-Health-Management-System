# Project Testing Evidence

Open these files during the assessment:

- `automated-test-log.txt`: captured output from the passing automated test run.
- `test-coverage-report.md`: feature and requirement coverage matrix.
- `manual-testing-record.md`: manual test cases and screenshot checklist.
- `bug-resolution-log.md`: defects, root causes, fixes, and verification evidence.

Run the suite again from `code/` with:

```bash
npm run test
```
